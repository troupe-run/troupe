# Spec Delta

## REMOVED Requirements

### Requirement: Refusals name the rule and the fix
**Reason**: The development workflow is the org's, not troupe's (Decision #25). Its spec now lives in
`troupe-run/infrastructure`, reworded to govern every repository the org builds in, troupe included.

**Migration**: The same requirement, in `troupe-run/infrastructure/openspec/specs/development-workflow`. The
guard that enforces it is delivered to troupe from there (troupe-run/infrastructure#8).
