# Proposal

## Why

OpenSpec 2.0.0 (released 2026-11-11) is now the version installed locally, while troupe's OpenSpec files were
generated by 1.14.3 (#423). 2.0 moves the skills to `.agents/skills/`, links them from tool folders such as
`.claude/skills/`, and removes the `/opsx:*` slash commands. `openspec update` deletes the old files, so the
repository and the names it tells people to type have to move together.

## What Changes

- **Regenerate the OpenSpec files with 2.0.0.** Run `openspec update` and commit exactly what it writes; no hand
  edits. Its dry run lists 25 changes:
  - adds `.agents/skills/openspec-*/SKILL.md` for the six workflows troupe uses (propose, explore, apply-change,
    update-change, sync-specs, archive-change), and `.agents/skills/.openspec-target`;
  - replaces each `.claude/skills/openspec-*/` directory with a link to its `.agents/skills/` copy;
  - **BREAKING** (for anyone typing them): deletes the six `/opsx:*` command files in `.claude/commands/opsx/`.
  The dry run lists no locally edited file to keep.
- **Name the 2.0 skills in CLAUDE.md.** Its workflow steps say `/opsx:propose`, `/opsx:apply` and `/opsx:archive`.
  They become `/openspec-propose`, `/openspec-apply-change` and `/openspec-archive-change`, the names the upgrade
  guide maps them to.

Nothing else changes here. Archived changes keep the names they were written with. `scripts/guard.py` and
`.github/workflows/guard.yml` also say `/opsx:*`, and `guard.yml` pins CI's OpenSpec to 1.14.3, but both are
delivered from troupe-run/infrastructure, so they change there (troupe-run/infrastructure#308), which waits for this.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

None. These are development tooling files and a contributor note. No troupe behaviour, and no requirement in
`openspec/specs/`, changes (none names a slash command or the skill folders), so the change sets `skip_specs: true`.

## Impact

- Changed: `.agents/skills/` (7 files added), `.claude/skills/openspec-*` (6 directories become links),
  `.claude/commands/opsx/` (6 files deleted), `CLAUDE.md`.
- Unchanged: `openspec/config.yaml`, `.claude/settings.json` (delivered), all code and tests.
- CI keeps validating with OpenSpec 1.14.3 until infrastructure#308 delivers the 2.0.0 pin. Its `openspec-strict`
  check reads only `openspec/`, whose format 2.0 doesn't change.
- Sessions still running on `/opsx:*` keep the commands they loaded; on a branch rebased onto this, the commands are
  gone and the same workflows are the `openspec-*` skills. The orchestrator tells them the names.
- Related: troupe-run/website#116 does the same for the website. troupe-run/infrastructure#308 moves the CI pin and
  the guard's messages once both have merged.
- Rollback: revert the commit.
